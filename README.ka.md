# Gargari Quiz

ტურნირული ვიქტორინა — „adventures" თემა, თამაშის ენერგია და არა ფორმის შევსება.

[In English](README.md)

რეპოზიტორია ორ ნაწილს შეიცავს:

| საქაღალდე | რა არის |
| --- | --- |
| `design/` | დიზაინის წყარო, 1:1 იმპორტირებული დიზაინის პროექტიდან. უბრალო HTML + JSX + CSS, ბრაუზერში იხსნება, pan/zoom ტილოზე ექვსივე ეკრანი გვერდიგვერდ. ეს არის ვიზუალური ეტალონი. |
| `app/`, `src/` | თავად აპლიკაცია — Expo / React Native, expo-router. |

## სტეკი

Expo SDK 57, React Native 0.86, React 19.2, TypeScript მკაცრ რეჟიმში. ერთი
კოდი iOS-ისთვის, Android-ისა და ვებისთვის. ნავიგაცია expo-router-ზეა,
მდგომარეობა zustand-ზე და AsyncStorage-ში ინახება, ანიმაცია Reanimated-ით UI
ნაკადზე მუშაობს, გრაფიკა react-native-svg-ზე, expo-linear-gradient-სა და
expo-blur-ზე დგას, დასრულების ეკრანებზე კი Lottie.

ეს ნამდვილი ნეითივ აპია და არა WebView, მაგრამ `ios/` და `android/`
საქაღალდეები რეპოში არ დევს — Expo Go-თი მუშაობს. `npx expo prebuild` მათ
დააგენერირებს, როცა მაღაზიისთვის ბილდი ან საკუთარი ნეითივ მოდული დაგჭირდება.

ნეითივ მოდულების ვერსიები **ზუსტად** არის დაფიქსირებული, caret-ის გარეშე. SDK-ს
მოსალოდნელი ვერსიიდან აცდენა სწორედ ისაა, რაც Expo Go-ს ტეხს, და შეცდომის
ტექსტიდან ამის მიხვედრა რთულია.

## ეკრანები

1. **არენა** — დიდი ტურნირის ბარათი ათვლითა და პრიზის გამოსახულებით,
   კატეგორიების სქროლი, რომელიც ბრძოლების სიას ფილტრავს, მანათობელი ტოკენების
   ბალანსი.
2. **ვიქტორინა** — 5-წამიანი ამოწურვადი ზოლი, ცენტრალური მედია-ბლოკი
   (anti-AI ფორმატის გული), ოთხი ტაქტილური ღილაკი spring ანიმაციით, 50/50.
3. **რეიტინგი** — შენი ადგილის ბანერი, პოდიუმი და სია, რომელიც დღის, კვირის,
   საერთო თუ მეგობრების ჭრილში გადალაგდება.
4. **საფულე და მაღაზია** — ბალანსი, ტოკენების პაკეტები, ოპერაციების ისტორია
   ledger-იდან.
5. **გამარჯვება** / 6. **დამარცხება** — ანიმირებული თასი და გატეხილი კომპასი.

არსებობს მეშვიდე ეკრანიც, რომელიც არავინ უნდა ნახოს: error boundary, root
layout-იდან ექსპორტირებული, რომელიც დაცემულ ეკრანს იჭერს და აპს გათეთრებას
არ ანებებს.

## რაუნდი

რაუნდი ათი კითხვაა ოცისგან შემდგარი ბანკიდან, გამეორების გარეშე. ადრე ბანკი
modulo-თი იყო შემოვლილი, ანუ ყოველი რაუნდი თითო კითხვას ორჯერ სვამდა და მეორე
ნახევარი უფასო ქულები იყო.

ხუთი წამი კითხვაზე, დრო კი კედლის საათით ითვლება და არა ათვლით — აპიდან გასვლა
მას არ აჩერებს. ფონში გადასვლით ფიქრი ერთადერთი ხვრელი იყო, რომელიც ნამდვილად
ღირდა დაეხურა თამაშში, რომლის მთელი აზრიც დროის ლიმიტია.

## ხელმისაწვდომობა

კონტროლებს აქვთ როლი, წარწერა და მდგომარეობა — მონიშნული თუ გათიშული.
მხოლოდ-იკონიანები დასათაურებულია; ტაბების იკონები კი ხელმისაწვდომობის ხიდან
დამალულია, რადგან ისინი ქვემოთ დაწერილ წარწერას იმეორებენ.

დიზაინი გამუდმებით მოძრაობს — mesh ფონი, ბალანსის შარავანდი, ლაივ წერტილი,
სერიის ცეცხლი, დასრულების კონფეტი. ყველაფერი ჩერდება, როცა სისტემა მოძრაობის
შემცირებას ითხოვს, და ჩერდება დასვენების მდგომარეობაში და არა ნულზე, რომ არ
დარჩეს შთაბეჭდილება, თითქოს რაღაც ვერ ჩაიტვირთა. ვიქტორინის ზოლი გამონაკლისია:
ის საათია და არა დეკორაცია.

## გაშვება

აპლიკაცია:

```bash
npm install
```

```bash
npm start
```

მერე QR კოდი **Expo Go**-თი დაასკანერე.

დიზაინის ტილო:

```bash
npm run design
```

გახსენი `Gargari Quiz.html`. React-სა და Babel-ს CDN-იდან იღებს, ანუ ინტერნეტი
სჭირდება, ბილდი კი არა.

ტიპები და ტესტები:

```bash
npm run typecheck
```

```bash
npm test
```

ტესტები ფარავს ეკონომიკას, კითხვების ბანკს, რეიტინგის მონაცემებსა და რიცხვების
ფორმატირებას — იმ ნაწილებს, სადაც წესებია და არა ლეიაუტი. `node --test`-ზე
მუშაობს, ფრეიმვორკის გარეშე.

## მდგომარეობა

ერთი zustand store (`src/store/game.ts`), AsyncStorage-ში შენახული: ტოკენების
ბალანსი, ქულები, სერია, ყველა ჩარიცხვისა და ხარჯვის ledger, რაუნდების ისტორია
და გადახდილი ტურნირები. ყველა ეკრანი აქედან კითხულობს, ამიტომ არენის ბალანსი
და საფულის ბალანსი ვერ დაშორდება ერთმანეთს.

მისი ფორმა განზრახ ისეთია, როგორსაც `GET /me` დააბრუნებდა — სერვერის გაჩენისას
store პასუხის ტიპად იქცევა.

## ლოკალიზაცია

ქართული და ინგლისური, გადამრთველი პროფილის ტაბშია, არჩევანი სხვა
მდგომარეობასთან ერთად ინახება.

პირველ გაშვებაზე აპი ტელეფონს მიჰყვება. `localePinned` განასხვავებს შეთავაზებას
არჩევანისგან: სანამ ის false-ია, სისტემის ენა იმარჯვებს; პროფილში ენის არჩევა
მას true-ზე გადაიყვანს და მას შემდეგ მოთამაშის არჩევანი რჩება, თუნდაც
ტელეფონის ენა შეცვალოს.

`src/i18n/en.ts` ერთდროულად ინგლისური ტექსტიცაა და ის ტიპიც, რომელსაც ყველა
სხვა ენა უნდა აკმაყოფილებდეს — გამორჩენილი ან გადარქმეული გასაღები ბილდს ტეხს
და არა ეკრანზე ცარიელ წარწერას ტოვებს. ჩასასმელი მნიშვნელობების მქონე
სტრიქონები ფუნქციებია და არა შაბლონები, რომ სიტყვათა რიგი მთარგმნელს დარჩეს.

ორი რამ, რაც დამწერლობამ მოითხოვა (`src/theme/`-შია):

- **ფონტები.** არც Bebas Neue-ს და არც Space Grotesk-ს ქართული ასოები არ აქვს —
  ორივე შემთხვევაში ყველა სიმბოლო კვადრატად დაიხატება. Noto Sans Georgian
  ორივე როლს ფარავს, ყველაზე მძიმე წონა კი შევიწროებულ სათაურის ფონტს ცვლის.
  ორივე დამწერლობა თავიდანვე იტვირთება, რომ გადართვისას კვადრატები არ გამოჩნდეს.
- **რეგისტრი და ზომა.** ქართულს მაიუსკული არ აქვს, ამიტომ წარწერების
  „პატარა კაპიტელი" გამორთულია და letterSpacing შემცირებული. Noto Bebas-ზე
  ბევრად განიერია, ამიტომ სათაურები ინგლისურის ~72%-ზეა და მეტ
  სასტრიქონთაშორისს იღებს. კოდში ისევ `size={48}` წერია, დანარჩენს
  `typeMetrics` აკეთებს.

კითხვების ტექსტი თავად კითხვებთან დევს (`src/data/questions.ts`) და არა
სტრიქონების ცხრილში — ის კონტენტია და სერვერიც ასევე დააბრუნებს.

რიცხვებს `src/lib/number.ts` აჯგუფებს და არა `toLocaleString()`, რომელიც
მოწყობილობის ლოკალეს კითხულობს და ერთ ეკრანზე „12,408"-ს „3 402"-ის გვერდით
დაბეჭდავდა.

## ვებიდან React Native-ზე გადატანა

დიზაინი CSS-ია; ზოგ ეფექტს RN-ში პირდაპირი შესატყვისი არ აქვს:

| დიზაინი (CSS) | React Native |
| --- | --- |
| `backdrop-filter: blur()` | `expo-blur` `BlurView` |
| ანიმირებული mesh გრადიენტი | `expo-linear-gradient` + Reanimated |
| `box-shadow: 0 4px 0` | ქვეშ დადებული `View` |
| CSS `@keyframes` | `react-native-reanimated` |
| ჩაშენებული `<svg>` | `react-native-svg` |
| Google Fonts `<link>` | `@expo-google-fonts/*` + `expo-font` |
| კონფეტი / ნაცრის ნაწილაკები | `lottie-react-native` |
